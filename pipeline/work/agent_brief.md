- 程度：`算好了` `算忙了`；`中々えいね`→`这不是蛮好的嘛`。

## 复查定例（2026-11-15 已译 13 文件复查后统一口径，翻译时保持一致）

- 「等子」只用于"等一下/稍等"义的 ちくっと；"再多一点"义（もうちっくと精進しぃ）不套等子。
- ちや 结尾断言 →「滴」；やね/やよ →「咯」；ぞね/ぜよ/き（催促断言）→「咧」或「啵」；ちゃろ →「啵」。
- けんど →「但是」（"仅仅/不过才"义的小さ instal けんど除外）。
- tag 问句（〜だよな？/そうやろ？/〜よな？）→「是没是？」（确信度高）或「是咩？」（求证）。
- ないんか？/〜ないやろ？求证反问 →「没是嘛？」（咩不接否定谓语）。
- 反诘（まさか/ありえんやろ？）→「咯？！」。
- えい 系按语气就近：疑问句内取「好」、应答取「得」、谓语"刚刚好"取「刚好得」、劝止取「得咧」；打发人「まあえいよ」→「得吧得吧」。
- 自问自答的「〜か…。」（无回答对象）→「……咩……。」口径。
- 嵌入式间接问句（能不能/要不要作宾语从句）不硬套「得不得」，按普通话自然句式。
- 桂柳话只落雅的方言线；雅切标准语/技术句时收干净（最多留一个咧/啵）。
- 标题翻译惯例：`メインストーリー`→`主线剧情`、`プレミアムストーリー`→`额外剧情`、`ExtraXXX`/`数字编号` 前缀保留、`＜前編＞/＜後編＞`→`＜前篇＞/＜后篇＞`。

## 翻译包格式（apply_pack 兼容）

每文件一个 JSON，写到 `pipeline/work/packs/`，命名 `pack_<file基名>.json`：

```json
{
  "file": "stories/dd_ch04_08_010.json",
  "title_zh": "……",
  "sub_title_zh": "……",
  "entries": [
    {"index": 0, "zh": "……", "narrator_zh": "雅"},
    {"index": 1, "zh": "……", "narrator_zh": ""}
  ]
}
```

- `file` 固定为源文件相对路径 `stories/dd_ch04_*.json`。
- `index` = entry 数组下标（从 0 数）。**必须覆盖所有需要 zh 的条目**（有假名→翻译；无假名→照抄）。
- `title_zh`/`sub_title_zh`：把 info.title / info.sub_title 译成中文（如 `002 メインストーリー`→`002 主线剧情`；`＜前編＞`→`＜前篇＞`）。
- 也可用数组形式 `{"file": ..., "zhs": [...], "narrators_zh": [...]}`（长度=entry 总数）。两种选一，推荐 entries。
- 写完后**自查**：JSON 能否被 `json.load`；entries 数量与源 entry 数量一致；逐条换行数一致。
