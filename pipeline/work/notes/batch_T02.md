# T02 批随读笔记（dd_ch04_08_101 / 08_102 / 09_010 / 09_020，共 457 条）

## 1. 剧情要点与因果链
1. **08_101（002 主线 大胆胜负～Case3～＜前篇＞，5月9日 7:01 PM 高校战→剧场休息室）**：燕、神乐入队后战力增强，真幌道出打工的真正用途＝把一定人数日常集中在固定地点，紧急出动时不抓瞎。雅质疑燕的安全性（"意外地冒失的小迷糊"）；真幌：**Tri-Gadget 持有者必须出战**，"能连接就能获得战斗之力"（婴儿老人也一样，只是不会真派婴儿上场）。关于燕的谜之力：管理厅拿不出明确答案，此事全权委任真幌；真幌私下承认"若干警惕"，但因"从未确认过的可怕力量"，判断放在手边看着最安心。
2. **雅的间谍推演升级**：燕不可能不知道那力量暴走会团灭三重奏→除非她握有"没问题"的确证→"燕从内部监视我们（间谍）的可能性很高"。雅对真幌设套：谎称黑进管理厅服务器拉回"燕力量相关的秘密文件"，真幌真实震惊（"真的假的！？"）→雅判定**真幌是白的**（非间谍，"连认真模式都没切，是真的在吃惊咯"），转而思考"证明燕是间谍的其他方法"。
3. **装睡钓鱼小剧场**：雅装睡发猪叫（ぶひ×3），钓到凑过来的搭档："以为我整天都在睡觉？为了钓你上钩我可一直醒着！"→"闲得要命"→被催干活。随后**潜入心之扉**（档案 04-154-77）：司书诊断"燕还没被确定为间谍，就先单方面认定她是黑的"，照此暴走会变成麻烦局面，请求搭档打倒令"我"焦躁的库兰（口上"献给我和$handle$的美妙的心灵之旅！"）。
4. **08_102（005 主线 后篇）**：战斗后雅自省（本话核心）——"燕是间谍尚未确定，却不知不觉以间谍为前提思考；一开始就带着定论去查，驷马真相都看不见"；自嘲差点"没证据也硬信＝与妄想无异"，并向搭档道谢"好像是被搭档救了咯"。关键态度：**怀疑归怀疑，不能把假设当前提**。
5. **钱汤日常（现实场景）**：雅抱怨"学校＋打工＋出击、零休息＝黑心企业都汗颜的劳动环境"，燕神乐表示不觉得黑（"刚入队觉得新鲜"）。燕提到在剧场碰到库兰们→雅开讲：**库兰＝人类灵魂脱离出来的东西；剧场是能安全保护它们的特殊设施**（外观只是冷清老剧场），具体构造雅自己也不知道（"嗯，不知道！"），打发为"超技术造的，更像秘密基地"。神乐盯着雅的胸部看→"我这胸部可保护不了库兰吧"→胸部大小攻防、燕"穿衣显瘦"梗。末尾章题卡【06 史上最爱的作战】。
6. **09_010（Extra002 事到如今！？【当地方言少女】，5月24日）**：燕问雅的方言算什么腔。三选项分支：A老实答土佐腔→雅吐槽搭档无趣（"这里本该随口编个不存在的语言名"）；B编"**古代詹加里亚语**"→雅大喜（赏房间零食），加布里埃拉神助攻编伪史（邪马台国旁"雀狩耶之国"的方言、超有名），燕全信还想讲给妈妈→雅起不祥预感；C"就说是立人设"→雅当场秀标准语、自曝前人设"超级装乖""在下腔"，燕完全没察觉是玩笑还期待下一任人设→雅最终坦白"我的方言是土佐腔"，燕仍理解为"土佐腔人设"。ぜよ梗：坂本龙马；女性不用ぜよ、现在男性也不用。
7. **09_020（Extra006 操场上的事【才没有拟人化呢】，5月31日）**：雅捡到脚受伤的小鸟，自称没得治疗技能，向 Bot（玩家）求助。分支：A交给燕→雅毒舌"选了让我最省事的选项是没是？""毕竟就是个bot咯"，仍自己带去保健室；B"总之先救救它"→"别瞎出主意……问的是我嘛，这次就依你咯"。后续燕私下向 Bot 打听雅为何心情差，三种解释分支（多管闲事/对鸟过敏/害羞掩饰）：过敏线→燕夺鸟自拎、雅训诫"bot说的话不能全信"；害羞线→燕信了、雅审出 Bot 传话内容，毒舌"那玩意终究是机器，半点感受不到这边的心情"，燕担心"惹她生气了吗？"。梗：保健室没有"只治人类"的招牌；"能找到宽宏大量的好夫婿就咯"。
