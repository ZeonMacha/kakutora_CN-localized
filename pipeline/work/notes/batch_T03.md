# 批次笔记 · T03（ch04 雅线：dd_ch04_09_101 / 09_102 / 10_010 / 10_020）

## 1. 本批剧情要点（因果链）
1. **09_101「恋之崎的日常＜前篇＞」**：5月13日晨，雅的日常——回笼觉、防备被 Bot（搭档）监视（"到底盯到哪一步了""只要无视就不会被看到咩？"），出门前开启"对外用的雅小姐模式"。校园线：食堂人多想去外吃→怕留级硬吃→美术课前自设"病弱人设 恋之崎子"。课间经 TOUCH 插件被搭档戳（"上次的报复"），随后潜入其内心世界（开放进程 0x815→0x2CC）：本次心之档案 **04-886-39** 内容＝"现实的我极想翘课，但放不下美术/体育总跟她配对、不在就落单的那孩子"。雅对"自己竟有这样的心灵"感到害臊（"是秘密"），最终搭档以"想看到温柔的雅"打倒库兰。
2. **09_102「＜后篇＞」**：写生课后，同班 **女子高中生A** 道谢"今天没出动、你能在真好"（同学视角默认雅缺课是因"出动"＝战斗任务，雅未否认）→ 女生追问翘课去向，雅答"不去据点、去安静的地方"；女生瞎猜"男朋友家"，雅反将一军（"也可能我对女人的兴趣大于男人哦？"）把对方噎住（呼应前篇美术课"那个她"的暧昧留白，防剧透不点破）。回家段：晚饭吃拉面的推特式借口（"自炊嘛，回老家吃了"）被搭档吐槽"这次是真的？"，雅借题发挥：网上只写真话的家伙没几个、立人设是理所当然，"对天真的搭档来说，网络的世界可能很危险哦"。末尾章题【07 爱，机器人】。
3. **10_010「瞥一眼」（Extra002）**：6月17日午休酷暑，雅敞开胸襟散热（"不是它自己开的咯，是我自己开的"），神乐慌忙制止；男生们轮流偷瞥，雅故意回敬"瞥。"并宣称"被看看又不会少块肉，真能少反而想全露"。对 WAVE 上的搭档输出歪理：偷瞥才有价值、求"给我看"没意义、"你是固定摄像头，想看也没得看咯"。
4. **10_020「西点新手」（Extra006）**：6月11日假日咖啡厅（**ためいきのシュガー＝【叹息的糖】** 秘语解锁）。雅自曝只做和食、西点从没做过但"喜欢的东西之一"——比起自己做更想吃专业做的那口，又怕"做太好吃收不住会吃胖"（自己不运动），所以刻意不碰西点；燕/神乐被带得齐声"我也不做蛋糕了"。后半互喂芭菲回礼战：雅"做的一方得咯，被做的一方头疼"，最终"……嗯，最棒咯"。
