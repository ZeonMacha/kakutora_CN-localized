# 柳州话疑问句规则摘要（据《柳州話的附加問句》黃笑赧 2024，中大《中国语文研究》103期）

供恋之崎雅（土佐腔→柳州话/桂柳话）问句翻译参照。**与文风.md 冲突时以文风.md 为准**（文风优先级最高）。

## 是非问句句末三语气词（对应普通话"吗"的三分）

| 柳州话 | 功能 | 普通话对应 | 用法要点 |
| --- | --- | --- | --- |
| **咩**（高平） | 中性询问，不预设答案 | 嗎1 | 句中不能出现表怀疑/猜测/诧异的副词或否定词；排除否定性谓语。例：`你去柳州咩？`＝你去柳州吗？ |
| **嘛** | 有倾向的求证，语气缓和，有疑而问 | 嗎2 | 后面可接测度的"吧"字句。例：`連十塊錢都沒有嘛？沒可能吧？` |
| **咯** | 反诘，语气强，疑少信多、强化肯定 | 嗎3 | 后接坚决主张"没可能啊！"。例：`連十塊錢都沒有咯？沒可能啊！` |

- 咯的确信度 > 嘛。是啵37/啵31：陈述句末＝告知/建议；疑问句末 `……啵31？` ≈ `……吧？`（商量、建议）。
- 柳州话是非问不靠语调，疑问信息全由语气词负载。

## "咩"后可再叠语气词（普通话"吗"不能）

| 形式 | 功能 | 例 |
| --- | --- | --- |
| 咩啦 | 究问/逼问，语气较缓，带商量 | `你去咩啦？`≈你到底去不去啊？！ |
| 咩咯 | 究问/逼问，语气强，不耐烦 | `你去咩咯？` |
| 是咩44啦 | 求证+怀疑，倾向认为命题为假（≈"不是吧？！"） | `明天下雨，是咩啦？` |
| 是咩44咯 | 求证+诧异，确信命题为假（最强语用否定，≈"不是吧？！！"） | `轻轨开通了，是咩咯？`≈不是吧？！ |

## 正反问（X没X）与否定反问（没X嘛/咯）

| 形式 | 功能 | 例 |
| --- | --- | --- |
| 得没得 / 得不得 | 祈使附加问：命令、劝阻（语气强硬）＝"行不行" | `掃下地，得沒得？`＝扫下地，行不行？ |
| 是没是 | 陈述附加问：寻求认同、增强语力；确信度高于"是咩"＝"是不是" | `你不服氣，是沒是？` |
| 没是嘛 / 没X嘛 | 反问：倾向于认定命题为真（有疑） | `他崽明年才考大學，沒是嘛？`＝不是吗？ |
| 没是咯 / 没X咯 | 反问：确信命题为真（无疑，坚决主张，最强肯定） | `還有米，沒是咯？` |

- 文风.md 规定（优先）：「可不可以」→「得不得」；「可以吗？」→「得咩？」或「得不得？」。
- 命令/强硬："得不得"；商请/客气："得咩""好咩""可以咩"（＝好吗/可以吗）。

## 其他要点

- **没曾**＝"还没/未曾"。问已然事件用"没曾"而非"了…咩"：`你吃飯沒曾？`＝你吃饭了吗？（据文风整体可读性原则，此类可酌情用"还没……咩？"）
- **啦**：只能用于疑问句末，语气缓和、商量（≈啊）。
- **晓得很/懂咩**："晓得咩？/懂咩？"＝明白吗？知道吗？
- 反问/感叹句后一般不再加附加问（柳州话不用"对吧？！"那种感叹+tag）。
- 附加问"没X嘛/咯"不能作话轮始发句，必须有前文铺垫（翻译时注意语境）。

## 翻译决策速查（雅的方言线）

1. 原文是单纯中性是非问（〜か？/〜の？/〜んか？）→ 句末"咩？"。
2. 原文带求证倾向（〜じゃないの？/〜んだよね？/〜ね？）→ "嘛？"。
3. 原文反诘（〜わけないじゃん/まさか〜）→ "咯？！"或"没X咯？！"。
4. 原文 tag（〜だよな？/〜ですよね？/そうだよね）→ "是咩？"（求证）或"是没是？"（求认同，确信度高）。
5. 原文可不可以/行不行（命令、催促）→ "得不得"；客气请求 → "得咩？/好咩？"。
6. 原文到底/究竟逼问 → "……咩啦？/……咩咯？"。
7. 原文提案/建议（〜しようか/〜いかが）→ "……啵？"或"……咧？"（≈吧？）。
8. 拿不准的确信度/语气分层 → 正常翻译句末并用 `[?]` 打标，不要硬套。
