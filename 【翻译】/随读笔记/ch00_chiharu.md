# ch00 千羽鹤专场（动画双轨叙事） · 随读笔记

## 1. 长期关键锚点与未解疑点（不随滑窗过期，已解即删）
- **叙事结构与双轨定位**：
  - **一周目（`anime_01~04`）**：`01~04` 为四位明线女主入线引导；`05~39` 为双轨叙事（`01` 线可 `assemble` 对齐 `02~04` 线），至 `ep 39` 决定实施**『替换』作战**，以神乐的第五频道（未观测的过去）为切入点回溯改写。
  - **二周目（`anime_05_*`，神乐线）**：紧接一周目完结之后，默认玩家已知晓世界真相，同步回顾过去与总意调查；导航员在**国政领火**、**红发千羽鹤（原初逢濑燕）**、**千羽鹤**与**索伊尔顿**之间切换。作战核心为先访问神乐心之扉，在逻辑上切断其脑干纳米机器 **Rediness** 与“他们”的通信，并通过不与记录影像冲突的微调（`替换`）改写至 2016 年末为止的走向。
- **关键设定与称呼**：
  - 表面上千羽鹤作为恋爱游戏引导角色出场，实际是与四位女主新司书缔结契约的幕后黑手、从逢濑燕内心诞生的自身库兰；回归本体后以「红发千羽鹤」姿态现身。红发千羽鹤本质是包裹日本的 PhenoMENON 本身的意志；燕因特殊脑器质而拥有千羽鹤与“可爱的燕”2 个自身库兰。
  - 量子服务器与世界地址（`セカイアドレス`）：`2EF4F`（千羽鹤连接世界）、`2E113`（领火连接世界，雅曾提及）、`15F9C`（外界 2032 年）；玩家世界由 TRI-OS 自动检索，存为量子比特变量未转数值。
  - 玩家与各导航员：`あなた` / `貴方` 统一译「你」（禁用「您」）；`せんばづる` 错读梗保留 `senbazuru`；`らぶとーく` 在动画线译作「恋爱对谈」；变量 `$handle$`、`$me$`、`$gcn$`、`$qiiz_seikai$`、`$dialog_word$` 原样保留。
  - 固定术语：`イチャコラ` → `腻歪`；`フェノメノン` → `PhenoMENON`；`トライナリー` → `三重奏`；`クラン` / `セルフクラン` → `库兰` / `自身库兰`；`デイドラ` → `每日剧场`；`リプレイス` → `替换`；`蒸着` → `蒸镀`；`ゾルタクスゼイアン` → `Zoltaxian`；`スタックポインタ` → `栈指针`；`ダイズバー` → `大豆营养棒`；`エンタングル` → `纠缠`（量子纠缠）；`にゃボット` → `喵Bot`；`にゃぼにゃすティー` → `喵博尼亚斯蒂`；`Rediness` 保留原文。
- **未解疑点**：
  - 神乐心之扉发生同化现象且未检测到外界入侵的真正原因仍未查明（领火猜测可能是外线被切断或燕的世界因纠缠规律破坏而与原世界彻底切离）。

## 2. 近期主线滑窗（保留近 3~4 章的因果、情绪转折与关键场景）
- **前情简摘（一周目 & 二周目 `ep 01～12`）**：一周目揭露皇千羽鹤与 Phenom 计划后决定以神乐 CH.05 实施**『替换』作战**。二周目 `ep 01～12`：领火说明回溯至 `2016-03-21` 并通报神乐心之扉发生同化危机；索伊尔顿公布统计；红发千羽鹤开展起重机思想实验并展示“素颜”冷峻一面；千羽鹤（“退休工薪少女/斯托千”）与玩家和解后开设【现在的小千锐评过去的小千！】栏目。
- **`anime_05_13.json`（ep 13·丰洲桥物语）**：**红发千羽鹤**公布起重机问题统计并剖析功利主义（最大幸福论），随后展开“异世界战争按钮”思想实验（需选出 `$gcn$` 代表最爱女孩，对方来电声称“不打算按攻击按钮”）。游乐园约会（过山车=濒死体验、旋转木马=利用动态视力让人好看 1.2 倍）后，她正式解析自身、千羽鹤与“可爱的燕”的三重关系（如月音羽→世界/忒耳普西科瑞的对照），并自述兴趣为折纸（纸鹤、东西南北）、听 FreyMENOW 歌、读地缘政治/哲学书（喜欢经验机器问题），直言无结婚愿望且拒绝为甜甜蜜蜜而撒谎。
- **`anime_05_14.json`（ep 14·NYABONYASTIE 第一卷）**：**千羽鹤**趁 MV 回 TRI-OS 进行 GC（垃圾回收）期间主持【三重奏猜谜大会！】（10 题，全对奖品为领火制作的定期刊库兰志『喵博尼亚斯蒂』第一卷附赠「蜘蛛型喵Bot NB-01A」，全 5 卷集齐可 4 破）。**领火**登场颁奖并从步行性能、多足功能、语音（96Khz/32GB 闪存猫叫）、量子 AI、24 节激光尾巴、不可拆卸猫脸六方面解说喵Bot。
- **`anime_05_15.json`（ep 15·救世主之王）**：**领火**宣布启动第 1 次**替换**试验运行：重申不能与记录影像产生矛盾，否则会引发类似“弑亲悖论”的严重后果（众人包括她与千羽鹤都会忘掉玩家并偏离可能性轴）。本次委托玩家在秋叶原约会时通过 WAVE 提议燕送神乐一对同款礼物，以减轻海边发症后的精神负担、为日后让神乐与皇千羽鹤对等谈判铺路（作战由千羽鹤“本人攻略本人”亲自立案）。
- **`anime_05_16.json`（ep 16·酸黄瓜）**：**领火**确认首次替换试运行顺利且仍未检测到外界入侵，提出“燕的世界是否已与原世界切离”的量子**纠缠**假说；对玩家在共通意识野听到的“还是同化比较好”之声尚无头绪。随后送达此前未能发送的**神乐表情包**，嘱咐在神乐最痛苦的时期用玩家的心意支撑她。
- **`anime_05_17.json`（ep 17·电脑工作人）**：**千羽鹤**先以【触摸交流】插件和“粪作发售日轮回纪念导演解说音轨”插科打诨，随即转入正经重话：确认玩家对领火与自己的信赖度，指出替换作战需要千羽鹤、领火与玩家**三位一体**，并坦言自己不认为替换前的行动是错的（因基于当时情报极限思考，否认才是撒谎），但愿接受玩家“不信赖但为了守护她而合作”的信念。预告下回正式启动替换作战。

## 3. 司书与角色口吻（合并提炼，保留对比句例）
- **千羽鹤**：冷静/低气压型，短句，用「你」，常抛冷笑话、谐音梗（`斯托千` / `千司吐` / `油淋小千` / `得意忘形夫`）与 Meta 发言。二周目恢复后对玩家的爱意会轻微露怯，谈及信赖与计划原则时则极其理性诚实（`不摆得意脸的小千就不是小千！` / `因为那是谎言，那才是真正缺乏诚实的行为。`）。
- **红发千羽鹤（原初的逢濑燕）**：柔和诚恳、带敬体，自称「我」，称玩家 `$handle$` /「你」；约会时显露不知“甜甜蜜蜜”为何物的笨拙与理系式分析（`让人看起来比平时美丽了大约1.2倍。`），拒绝迎合撒谎（`你连撒谎也要甜甜蜜蜜吗？`）。
- **国政领火**：孩子气、亲切随和，开心时拉长音（～），句尾多「呀」「啦」，偶以 `空——空。`（`コーンコン。`）打招呼；称呼雅、燕、神乐、绫水（`小绫`）等皆去敬称。
- **索伊尔顿（`ソイルトン`）**：量子 AI 虚拟人格，礼貌理性带机械冷幽默，对玩家用「你」。
- **卯月神乐**：对玩家礼貌带撒娇，用自然「你」；仅原文有 `ぴょん` 时才加 `pyon`。
