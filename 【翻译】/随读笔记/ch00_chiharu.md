# ch00 千羽鹤专场（动画双轨叙事） · 随读笔记

## 1. 长期关键锚点与未解疑点（不随滑窗过期，已解即删）
- **叙事结构与双轨定位**：
  - **一周目（`anime_01~04`）**：`01~04` 为四位明线女主入线引导；`05~39` 为双轨叙事（`01` 线可 `assemble` 对齐 `02~04` 线），至 `ep 39` 决定实施**『替换』作战**，以神乐的第五频道（未观测的过去）为切入点回溯改写。
  - **二周目（`anime_05_*`，神乐线）**：紧接一周目完结之后，默认玩家已知晓世界真相，同步回顾过去与总意调查；导航员在**国政领火**、**红发千羽鹤（原初逢濑燕）**、**千羽鹤**与**索伊尔顿**之间切换。作战核心为先访问神乐心之扉，在逻辑上切断其脑干纳米机器 **Rediness** 与“他们”的通信，并通过不与记录影像冲突的微调（`替换`）改写至 2016 年末为止的走向。
- **关键设定与称呼**：
  - 表面上千羽鹤作为恋爱游戏引导角色出场，实际是与四位女主新司书缔结契约的幕后黑手、从逢濑燕内心诞生的自身库兰；回归本体后以「红发千羽鹤」姿态现身。红发千羽鹤本质是包裹日本的 PhenoMENON 本身的意志；燕因特殊脑器质而拥有千羽鹤与“可爱的燕”2 个自身库兰。
  - 量子服务器与世界地址（`セカイアドレス`）：`2EF4F`（千羽鹤连接世界）、`2E113`（领火连接世界，雅曾提及）、`15F9C`（外界 2032 年）；玩家世界由 TRI-OS 自动检索，存为量子比特变量未转数值。
  - 玩家与各导航员：`あなた` / `貴方` 统一译「你」（禁用「您」）；`せんばづる` 错读梗保留 `senbazuru`；`らぶとーく` 在动画线译作「恋爱对谈」；变量 `$handle$`、`$me$`、`$gcn$`、`$qiiz_seikai$`、`$dialog_word$` 原样保留。
  - 固定术语：`イチャコラ` → `腻歪`；`フェノメノン` → `PhenoMENON`；`トライナリー` → `三重奏`；`クラン` / `セルフクラン` → `库兰` / `自身库兰`；`デイドラ` → `每日剧场`；`リプレイス` → `替换`；`蒸着` → `蒸镀`；`ゾルタクスゼイアン` → `Zoltaxian`；`スタックポインタ` → `栈指针`；`ダイズバー` → `大豆营养棒`；`エンタングル` → `纠缠`（量子纠缠）；`にゃボット` → `喵Bot`；`にゃぼにゃすティー` → `喵博尼亚斯蒂`；`Rediness` 保留原文。
- **未解疑点**：
  - 神乐心之扉发生同化现象且未检测到外界入侵的真正原因仍未查明（领火猜测可能是外线被切断或燕的世界因纠缠规律破坏而与原世界彻底切离）。

## 2. 近期主线滑窗（保留近 3~4 章的因果、情绪转折与关键场景）
- **前情简摘（一周目 & 二周目 `ep 01～17`）**：一周目揭露皇千羽鹤与 Phenom 计划后决定以神乐 CH.05 实施**『替换』作战**。二周目 `ep 01～17`：领火说明回溯至 `2016-03-21` 并通报神乐心之扉发生同化危机（`2E113` 藏身与量子**纠缠**切离假说）；红发千羽鹤开展起重机与“异世界战争按钮”思想实验并剖析三重关系；千羽鹤与玩家确立**三位一体**合作，并随『喵博尼亚斯蒂』第一卷送出「蜘蛛型喵Bot」；首次替换试运行中玩家促成秋叶原同款礼物并送达神乐表情包。
- **`anime_05_18.json`（ep 18·神乐说不做人了）**：**红发千羽鹤**公布“攻击按钮”统计（52.8% 按 vs 47.2% 不按）及按各女主支持群体划分的差值表（卯月支持者最倾向按、领火支持者最倾向不按），指出个人框架内无 True End、关键在于是否后悔。随后预告与自己的约会暂告一段落，邀请玩家在夜景“成熟约会”中告白尝试接吻却临阵害羞放弃，闲聊中闹出把“夏款（ファッション）”听成“夏季水果（梅子/西瓜）”的乌龙。最后切至 `2016-07-28`（海边事发日），预告下回将进入是否介入世界的 `FIX` 抉择。
- **`anime_05_19.json`（ep 19·有多少份记忆，就拥抱多少次）**：**领火**得知蹦子在同化中消失后自责并决定亲自前往神乐心之扉；随后正式公开以 **`2E113` 世界为媒介**进行**蒸镀**的方案——将燕的 PhenoMENON 全信息复制至空白的 `2E113`，再让燕正常收束，从而保住燕作为人类的肉身并消除战败焦土记忆矛盾。作战第一步要求玩家在神乐被直升机带走前，诱导皇长官对神乐**说谎违约**（使其契约失效），再让神乐向长官提出接受 `2E113` 方案。
- **`anime_05_20.json`（ep 21·NYABONYASTIE 第二卷）**：注：文件内开场标记为 `アニメ第21話`（对应第 21 话 MV 回 GC 期间）。**千羽鹤**主持【与三重奏的猜拳大会！】（燕、绫水、加布里埃拉、雅、神乐 5 人全员登场，神乐胜负±2币，其余±1币），集齐 10 枚猜拳币可获『喵博尼亚斯蒂』第二卷（1 破喵Bot）。**领火**登场解说 8 足多脚优势（时速 30 公里、防翻倒）及开发秘闻：喵Bot 因学习了“护小绫”与“机器人三定律”的二律背反，在领火撕毁小绫训练照片时从背后轻射一记尾巴激光示警。结尾玩家可向领火反馈上一回未见千羽鹤与替换选项的调谐异常。
- **`anime_05_21.json`（ep 20·幸福的华尔兹）**：注：文件内开场标记为 `アニメ第20話`。**红发千羽鹤**让玩家在『想和她们腻歪卿卿我我』与『想参与世界的选择』间签署最终协议（`FIX`）。若选择参与世界，她会进一步询问玩家是否愿意“成为我的左右手”，并阐述“由少数铁板一块的智囊掌舵”的理念。随后在 `2016-08-30` 节点委托玩家通过 WAVE 向千羽鹤进言，让她对卯月的尖锐提问说出实话。

## 3. 司书与角色口吻（合并提炼，保留对比句例）
- **千羽鹤**：冷静/低气压型，短句，用「你」，常抛冷笑话、谐音梗（`斯托千` / `千司吐` / `油淋小千` / `得意忘形夫`）与 Meta 发言。猜拳回主持风格干脆利落（`少挑刺。` / `那种地方就该读懂空气顺着同意才对。`），谈及信赖与计划原则时极其理性诚实（`因为那是谎言，那才是真正缺乏诚实的行为。`）。
- **红发千羽鹤（原初的逢濑燕）**：柔和诚恳、带敬体，自称「我」，称玩家 `$handle$` /「你」，对其他女主称呼去敬称（`卯月`、`领火`、`燕`）。约会时显露不知“甜甜蜜蜜”为何物的笨拙、理系式分析与天然呆误解（`把“夏款”听成梅子出货量` / `你连撒谎也要甜甜蜜蜜吗？`），主动提出“左右手”邀约时略带腼腆试探。
- **国政领火**：孩子气、亲切随和，开心时拉长音（～），句尾多「呀」「啦」，偶以 `空——空。`（`コーンコン。`）打招呼；称呼雅、燕、神乐、绫水（`小绫`）等皆去敬称。
- **索伊尔顿（`ソイルトン`）**：量子 AI 虚拟人格，礼貌理性带机械冷幽默，对玩家用「你」。
- **恋之崎雅（猜拳回客串）**：落桂柳话（`唔，输了咩。猜拳这种胜负事我就是不擅长啵。` / `想赢过我还早了88年咧。`）。
- **卯月神乐**：对玩家礼貌带撒娇，用自然「你」；仅原文有 `ぴょん` 时才加 `pyon`，自称 `ぴょんこ` 时译 `蹦子`（`是蹦子赢啦——♪`）。
