# ch03 加布里埃拉线 · 随读笔记

## 1. 长期关键锚点与未解疑点（不随滑窗过期，已解即删）
- **对玩家与「玛尔赞娜」的多重关系**：加布在 WAVE 上把玩家当作幻想朋友「玛尔赞娜」倾诉（第 11 章甚至称其「靠得住的管家」）。现实加布此时对「光（ヒカル）」抱有好感，而内心原司书玛尔赞娜则明确表示自己更喜欢 `$handle$`（第 18 章再次直白告白「我果然还是很喜欢 `$handle$`……最喜欢了」），并解释“体内不同人格有不同主张，统合在一起的才是现实的我”（尚留伏笔：为何司书玛尔赞娜会对 `$handle$` 抱有好感；第 16 章玛尔赞娜也坦言不清楚其他人格的想法）。
- **玛尔赞娜的“十字架”伏笔**：第 18 章在心之房间被 `$handle$` 追问是否真的毫无心结时，玛尔赞娜举婚姻欺诈作比喻，强调“心中有伤痕与‘现在过得很幸福’是两码事”，并在被追问“难道这么小就遭遇过婚姻欺诈”时罕见失态打断话题，要求对方忘掉刚才的话（待后续揭晓其背负的“十字架”真相）。
- **心因性失声症（仅对一定年龄以上男性发不出声）**：第 15 章现实加布在 WAVE 上向 `$marzanna$` 坦白并非男性恐惧症或洁癖，而是“心因性失声症”（面对小孩正常，面对一定年龄以上男性发不出声音），尚不知其具体成因；内心原司书玛尔赞娜本欲借门扉让 `$handle$` 解决，却发现烦恼正涉及 `$handle$` 本人，总意只允许暂且透露一点苗头，真正理由待后续揭晓。
- **与燕的关系里程碑**：第 11 章加布终于向燕坦白“一直害怕她那股神秘力量及穹顶战时宛如另一人般的神情”，正式道歉并取消「前辈」称呼与敬语（燕改口直呼「加布」），两人约定若燕将来失控，加布会亲手全力打醒并阻止她。
- **对绫水的“空壳”伏笔**：第 13 章内心原司书玛尔赞娜向 `$handle$` 坦言，她既喜欢绫水也有不喜欢的一面，因为“现在的绫水只是一具空壳（中身が無い）”，而现实加布似乎察觉到了又似乎没察觉，只能带着莫名欲求依赖她（待后续揭晓）。第 15 章潜入时加布进一步犀利指出绫水总是看周围脸色行事、缺乏主见才会放弃剑道。
- **固定译法与细节**：`ガブちゃん先輩` 译 `加布前辈`；真幌/绫水司书称呼 `ギャヴィ` 译 `加维`；`まゆちん` 译 `小茧`；宿舍 `とらいあんぐる` 译 `宿舍“三角”`；波兰土豆煎饼 `プラツキ` 译 `普拉茨基`；手游 `カプドラ` 译 `卡普多拉`；`ギガスマートエキスポ / ギガスマ` 译 `GigaSmart博览会 / GigaSma`；秘语 `【白昼夢の迷宮】` 译 `【白日梦的迷宫】`、`【別名は花子さん】` 译 `【别名是花子】`、`【それが子供の仕事】` 译 `【那就是孩子的本分】`、`【闇夜に霜の降る如く】` 译 `【犹如暗夜降霜】`、`【口にする日を】` 译 `【说出口的那天】`；厅内干部隐语 `四角ダルマ` 暂译 `四方达摩`。

## 2. 近期主线滑窗（保留近 3~4 章的因果、情绪转折与关键场景）
- **15（无法开口的理由＜前/后篇＞ / 额外剧情）**：
  - **主线**：7月20日傍晚在剧场小卖部打工时，加布面对圣翔和光一言不发，令圣翔误以为自己惹到她。潜入心灵领域时，绫水（称加布「加维」）罕见串门至加布的[心之扉]，加布犀利指出绫水总是看周围脸色行事才会放弃剑道；随后玛尔赞娜呼叫门扉（`0x221`→`0xFCE`）发现此次烦恼竟涉及 `$handle$` 自己，与绫水私下商议后决定先只透露一点苗头（千羽鹤则在末尾现身吐槽玩家多周目回溯选项）。后篇现实中，加布在 WAVE 上向 `$marzanna$` 坦白自己是「心因性失声症」，由玩家借闹钟与代答替她向圣翔、光传达“现在还请先等等”（含声音被诅咒/魅惑男人搞笑分支），光贴心拉走圣翔解围令加布心生感动。
  - **额外剧情**：`010 小小思乡病`（7月11日课间，地理课提到波兰引发思乡，燕与雏、茧争着挽留她，玩家发特攻队低配COS搞笑图逗笑众人）；`020 展览会`（7月10日休假，加布看浮世绘展迷路偶遇打工中的茧，带路后好奇跟踪却被甩掉）。
- **16（私人时间＜前/后篇＞ / 额外剧情）**：
  - **主线**：7月22日（PhenoMENON发生2天前）放学后，雏与茧邀加布去咖啡店一起联机刷手游「卡普多拉」新活动，加布对“放学后私人时间”的界限感感到犹豫。潜入心灵领域后，玛尔赞娜呼叫门扉（`0x333`→`0xFCC`）聊起公私时间观念、对日本下班聚餐文化的困惑，并坦言虽珍视 `$handle$` 却不清楚其他人格的想法。后篇现实中，加布决定同行并在咖啡店与雏、茧合作通关关卡6；随后茧提到配合「GigaSmart博览会（GigaSma）」的3日限定活动及匹配对战的恶性刷战利品BUG，加布坚持游戏规则与公平，决定尽早向官方举报。
  - **额外剧情**：`010 拿手好戏`（7月21日剧场打工，加布轻松修好圣翔的气枪并聊起留在波兰老家的真枪保养）；`020 试胆大会与女学生`（7月19日晚附属学园试胆，加布遇自称学生会副会长的女高中生，汇合后得知真副会长是2米肌肉男且请假中，众人吓跑；实为真幌变装）。
- **17（礼仪还是娱乐＜前/后篇＞ / 额外剧情）**：
  - **主线**：7月24日（PhenoMENON战结束当晚 7:59 PM），加布因神乐擅自行动而不快，见燕袒护神乐便自称“敌对派”先行离开；随后从雏与茧处得知本次 PhenoMENON 的诱因正是「卡普多拉」恶性 BUG，加布因当时未打电话催促官方修复而心怀愧疚。潜入心灵领域后，玛尔赞娜呼叫门扉（`0x58F`→`0x224`）向 `$handle$` 剖白这份无处安放的负罪感；后篇 WAVE 上加布与玩家聊起“既非预言家也无法预测发病”后释怀，得知官方已悄然修复 BUG 开启新活动，最终被雏、茧拉去打一局活动副本转换心情。
  - **额外剧情**：`010 多放点假`（7月26日，加布与雅向真幌讨要更多休假，得知剧场是真幌先祖自明治前传下的历史场所后立刻被日本文化打动，随后坦言只是想和初中同学一样多点玩耍时间，婉拒只给自己减班）；`020 一展身手`（6月25日休假午后，加布在户外射击场刷新圣翔最高分，在 WAVE 上向玛尔赞娜商量是否接受圣翔的让步请求，分支含“让步后险胜”与“真刀真枪94:96惜败后不甘加练”）。
- **18（总觉得不对劲＜前/后篇＞ / 额外剧情）**：
  - **主线**：7月27日（暑假前夕放学后 3:15 PM），加布去 CD 店找 MENOW 的 CD 想借此了解神乐，偶遇同样纠结的绫水；绫水觉得卯月一直隐瞒 MENOW 身份，趁机买 CD 试探像“趁人之危”而犹豫不前，加布一度动摇。潜入心灵领域（`0x122`→`0x9BF`）后，玛尔赞娜先因被 `$handle$` 质疑“是否真的幸福”而短暂失态，随后就“是否该打探他人秘密”与玩家探讨：比起死守字面规矩、见死不救，她更看重出于善意去了解对方。后篇现实中，加布坚持“神乐从不主动开口，不行动就永远无法了解”，说服绫水一同买下 CD，嘴硬否认“想和神乐搞好关系”却仍抱有一丝期待。
  - **额外剧情**：`010 梦想的打工`（7月15日午后咖啡店，雏与茧羡慕女服务员可爱制服，加布表面严厉提醒燕随时候命、曾险些被真幌买运动服当剧场制服，实则自己也很想穿可爱制服，约定解决 PhenoMENON 赢回自由后去尝试）；`020 能说出口吗？`（7月17日午后剧场打工，圣翔与光替加布搬运沉重的放映机零件，加布因失声症无法亲口道谢而懊恼，分支可由玩家在 WAVE 上代发道谢/恶搞中二/吹捧台词替她解围或惹她羞恼）。

## 3. 司书与角色口吻（合并提炼，保留对比句例）
- **玛尔赞娜（加布原司书）**：顶着 `ガブリエラ` 头衔，语气比现实加布更活泼轻快、俏皮（常用 `♪`、`～`），自称「我（あたし）」及「傲娇成分为零的人格」，称玩家「你」或 `$handle$`。坦率直白，能调侃玩家，也会用技术指令呼叫门扉（`开放进程，从0x122号地址前往0x9BF号地址。` / `搜索完成♪`），偶用波兰语 `Zrozumiałam!` 与宅梗；但在触及“自身背负的十字架”等核心伤痛时会突然激动失态并强行终止话题。
- **加布里埃拉（现实 / WAVE）**：傲娇嘴快、自尊心强、爱指使人（保留 `Escort` 等外语词与二次元梗），对熟人常口嫌体正直；但在 WAVE 私聊「玛尔赞娜」时显露依赖与率真。
- **来访的绫水（第 15 章心之扉串门）**：语气温和从容且略带俏皮（称加布 `加维`，称玩家 `$handle$`，偶用 `拜・托・啦♪`），替加布解围与打圆场。
