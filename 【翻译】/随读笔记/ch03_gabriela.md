# ch03 加布里埃拉线 · 随读笔记

## 1. 剧情脉络与动态关系
- **07（对队长所期望的是 / 额外剧情）**：主线作战中加布因接连被真幌与绫水安排去援护新人及担任狙击而闷闷不乐，怀疑自己未被真正信赖；潜入心之扉并由玩家引导绫水当面说出“最信任你”后，加布重拾干劲。额外剧情展现了她电车睡过头迟到与美术课不擅长上色的日常，对绫水的关心口嫌体正直，且在 WAVE 上依然把玩家当作幻想朋友「玛尔赞娜」倾诉。
- **08（大胆对决～Case2～ / 额外剧情）**：主线中加布因觉得新人抢了风头且自己总无法主动向绫水搭话而烦闷，潜入心灵领域时玛尔赞娜自嘲“被派来做司书或许意味着自己是多余的人格”，并判断病因是“绫水成分枯竭”。打倒阻碍搭话的库兰后，加布在钱汤更衣室经 WAVE（玛尔赞娜）引导向绫水开口——问战斗表现线获绫水明言“能放心把后背托付给你”，而“表白喜欢”线则因 `アタック`（恋爱攻势/战斗进攻）双关引发鸡同鸭讲的爆笑误会。额外剧情收录了加布在绫水房间听闻“活鱼刺身”与“活吞小鱼”后对和食产生心理阴影，以及在图书馆找日本文化书却被雅安利轻小说的日常。
- **09（班级的实情＜前/后篇＞ / 额外剧情）**：主线围绕加布想与燕搞好关系却又拉不下脸而陷入纠葛。燕因加布午休偷偷探头看她教室而担心过来搭话，结果在初中部大喊“前辈”引发周围学生误解，加布嘴硬把燕气走后，在 WAVE 向玛尔赞娜否认；切入内心世界后，原司书玛尔赞娜呼叫门扉（`0x578`→`0x19D`）查明是加布因“太想和燕做朋友却无法坦率”而濒临生出库兰。战后加布在 WAVE 被玩家套出“燕其实有点治愈自己”的真心话，随后燕经玩家提醒鼓起勇气邀加布喝咖啡并直球告白“想做朋友”，加布傲娇回绝过头反把燕弄到哭着鞠躬道歉，只得慌忙哄人。额外剧情收录了众人因无声电影展开讨论（绫水极度害怕恐怖片而在 WAVE 慌乱打错字求救），以及加布试图让燕在初中部改口不叫“前辈”却无论直呼其名还是叫“加维”都觉得别扭、最终只能妥协的日常。
- **10（不去七夕祭典吗？＜前/后篇＞ / 额外剧情）**：主线中燕、神乐与雅邀加布同逛七夕祭典，加布嘴硬拒绝并在被追问时失言指责燕“不连接也能破坏库兰、太过危险”，遭神乐与雅严厉指责。切入内心世界后，原司书玛尔赞娜呼叫门扉（`0x9FE`→`0x884`）查明真正症结并非讨厌燕，而是“生于战场的加布对其他成员在 PhenoMENON 增多、燕之谜未解时仍悠哉逛庙会感到愤懑”，却误将这股情绪当成了对燕的排斥。战后加布想道歉却因顽固自尊改口成“收回前言”，反倒是燕体谅她并立下“在祭典前查明自身力量真相”的约定；加布被燕的执着打动，经 WAVE 向玛尔赞娜（玩家）求教后，傲娇地提出“由燕负责当 Escort 让自己度过一生难忘的祭典”作为条件答应同行。额外剧情收录了加布不小心买重相扑门票而犹豫约谁同行（雅想扔坐垫、绫水欣然应允、燕满怀期待），以及因电影《木星危机》波兰与日本分级差异而在 WAVE 询问玛尔赞娜（玩家）是否该偷看、被一句“会变成不良少女”吓得决定再忍一年的日常。

## 2. 司书与角色口吻补充
- **玛尔赞娜（加布原司书）**：虽顶着 `ガブリエラ` 头衔说话，但语气比现实加布更活泼轻快、略带俏皮（常用 `♪`、`～`），自称「我（あたし）」，对玩家称「你（貴方）」或 `$handle$`。会坦率剖析加布“嘴硬、比常人更渴望被人陪伴”的性格，把防卫本能强的一面称为「soldier那边的我（ソルジャーのあたし）」，并会在心之扉用技术指令搜索门扉（`开放进程，从0x112号地址前往0x31B号地址。` / `搜索完成♪`）。第 08 章中还使用波兰语 `Zrozumiałam!` 及宅梗“绫水成分枯竭（アーヤ分が枯渇）”。第 09 章中继续以轻快口吻调侃现实加布的笨拙，并以 `0x578`→`0x19D` 呼叫门扉查阅心灵档案编号 `03-596-15`。第 10 章前篇以 `0x9FE`→`0x884` 呼叫门扉后推翻了自己“又是因燕而起”的先入为主猜测，对玩家夸加布是“三重奏的良心”时也会略显害羞，同时指出加布因战场地带出身而混淆了“放松”与“松懈”。
- **加布里埃拉（现实 / WAVE）**：对绫水及新人话题嘴快易炸毛，但私下在 WAVE 对「玛尔赞娜」倾诉时则更显率真与依赖；第 08 章在钱汤更衣室面对玩家的“神谕”调侃会慌乱吐槽，被强制挂断时打字截断为 `等等玛尔z`。第 09 章在 WAVE 会先嘴硬否认再被迫承认“燕治愈了自己一点点”，并对玛尔赞娜放狠话“敢说出去绝不轻饶”；现实中极度在意周围初中同学的视线，一旦把燕弄哭又会立刻慌神。第 10 章现实中因拉不下脸道歉而出现谐音急转弯（`……前——`→`……收回前言。`），在 WAVE 会认真纠结“波兰分级未满高中生不能看”的规则，在现实则保留 `Escort` 等外语词用法并以此作为傲娇让步的台阶。
