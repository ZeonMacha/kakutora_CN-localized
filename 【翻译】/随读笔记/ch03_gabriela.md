# ch03 加布里埃拉线 · 随读笔记

## 1. 长期关键锚点与未解疑点（不随滑窗过期，已解即删）
- **对玩家与「玛尔赞娜」的多重关系**：加布在 WAVE 上把玩家当作幻想朋友「玛尔赞娜」倾诉（第 11 章甚至称其「靠得住的管家」）。现实加布此时对「光（ヒカル）」抱有好感，而内心原司书玛尔赞娜则明确表示自己更喜欢 `$handle$`，并解释“体内不同人格有不同主张，统合在一起的才是现实的我”（尚留伏笔：为何司书玛尔赞娜会对 `$handle$` 抱有好感，待后续揭晓）。
- **与燕的关系里程碑**：第 11 章加布终于向燕坦白“一直害怕她那股神秘力量及穹顶战时宛如另一人般的神情”，正式道歉并取消「前辈」称呼与敬语（燕改口直呼「加布」），两人约定若燕将来失控，加布会亲手全力打醒并阻止她。
- **对绫水的“空壳”伏笔**：第 13 章内心原司书玛尔赞娜向 `$handle$` 坦言，她既喜欢绫水也有不喜欢的一面，因为“现在的绫水只是一具空壳（中身が無い）”，而现实加布似乎察觉到了又似乎没察觉，只能带着莫名欲求依赖她（待后续揭晓）。
- **固定译法与细节**：`ガブちゃん先輩` 译 `加布前辈`；真幌称呼 `ギャヴィ` 译 `加维`；宿舍 `とらいあんぐる` 译 `宿舍“三角”`；波兰土豆煎饼 `プラツキ` 译 `普拉茨基`；章节曲目 `【09 パーフェクトイエロー】` 译 `【09 完美黄】`、`【10 江戸川橋物語】` 译 `【10 江户川桥物语】`、`【MV EXE_AYAMi】` 原样保留；厅内干部隐语 `四角ダルマ` 暂译 `四方达摩`。

## 2. 近期主线滑窗（保留近 3~4 章的因果、情绪转折与关键场景）
- **11（加布前辈＜前/后篇＞ / 额外剧情）**：
  - **主线**：七夕祭后，燕因误会强行撮合加布与光独处而登门道歉，加布心口仍堵却说不清缘由。潜入心灵领域后，原司书玛尔赞娜直言现实加布喜欢光、而司书的自己更喜欢 `$handle$`，并呼叫门扉（`0x58F`→`0x224`）查明此次郁结是对迟迟无法向燕坦率道歉的焦躁，请玩家打倒“自尊心化身”库兰。后篇现实中，加布拉燕一起做波兰家常料理「普拉茨基」，经 WAVE 向玛尔赞娜（玩家）确认后，向燕正式道歉、取消「前辈」称呼与敬语，坦白对燕神秘力量的恐惧并立下“失控就揍醒你”的约定，燕感动改口直呼「加布」。
  - **额外剧情**：`010 加布里埃拉日记`（打工时在日记里混写愿望被神乐误当小说）；`020 来收拾一下吧`（休息室堆满加布捡来的小物件，嘴硬擅长收纳却不知如何处置）。
- **12（被拜托美言几句＜前/后篇＞ / 额外剧情）**：
  - **主线**：雏、圣翔、光、茧想瞒着燕在神乐坂三重奏剧场打工，央求加布向东云真幌说情。真幌断然拒绝后，茧竟冷不丁道出厅内干部隐语「四方达摩（四角ダルマ）」，引得真幌震怒盘问国家机密来源，茧则趁机提议把四人收作直属跑腿。加布在 WAVE 上安抚「玛尔赞娜（玩家）」并嘴硬表示不用多管，内心却仍想帮忙。潜入心灵领域后，原司书玛尔赞娜呼叫门扉（`0x58F`→`0x224`）确认加布总意确实想伸出援手，向 `$handle$` 征集说服真幌的理由。后篇现实中，加布以省力、防泄密与防止擅自行动为由说服真幌，并咬牙揽下担保，四人正式入职剧场（茧当场因真幌威压晕倒）。
  - **额外剧情**：`010 关于御好烧`（嫌广岛风分量多且讨厌自己动手煎）；`020 大家的朋友是？`（7月2日剧场日常，被燕问及朋友时，雏等人主动自称是加布的朋友令她感动差点落泪，或经 WAVE 提示把「玛尔赞娜」当作秘密朋友夸赞）。
- **13（追踪？＜前/后篇＞ / 额外剧情）**：
  - **主线**：6月21日休假午前，加布让绫水顺路载她去车站（看日本画展最后一天），邀约同行遭拒，绫水称要与小夜等人开学习会。加布觉得绫水神情过于雀跃可疑，欲跟踪一探究竟。潜入心灵领域后，原司书玛尔赞娜呼叫门扉（`0x993`→`0xFEC`）确认加布总意确实在意绫水去向，并坦言自己傲娇成分为零、对绫水感情复杂（认为现在的绫水只是“空壳”），希望借此更了解绫水。后篇现实中，加布尾随至区民中心旁的幼儿园，撞见绫水在为孩子们表演人偶剧，正欲撤退时被小朋友当成可疑人员发现；绫水虽叹气早料到会暴露，却未生气并拉加布一同向孩子们解释。
  - **额外剧情**：`010 在图书馆学习`（6月29日，加布首考70多分，与燕、雏、茧开学习会，分支含参观满屋法国人偶的加布房间/去咖啡厅/去图书馆围观情侣演恋爱喜剧）；`020 加布里埃拉的心意`（7月12日午休，加布留恋与燕等人的相处却羞于亲口说出“因为是朋友”，在 WAVE 上急忙打字被误认为收到暗杀委托）。
- **14（额外剧情 · 绫水MV回）**：
  - `010 与国政绫水急速拉近距离！`（7月9日午后，加布去还书发现通宵写报告后熟睡的绫水，在 WAVE 上否认“百合”自称正常向；分支含意外跌倒被绫水摸出太瘦遭叮嘱好好吃饭，或偷摸头发和脸蛋被装睡的绫水全听见而羞恼逃走）。
  - `020 与国政绫水大迟到！`（7月14日清晨，加布慢跑后睡回笼觉差点迟到，绫水破天荒未说教并骑摩托送她到校；经 WAVE 对「玛尔赞娜（玩家）」疑惑后道谢，得知绫水因早起拉伸知情才没生气，并在绫水自省“是不是性格太凶”时主动揽责安抚，体现两人关系缓和）。

## 3. 司书与角色口吻（合并提炼，保留对比句例）
- **玛尔赞娜（加布原司书）**：顶着 `ガブリエラ` 头衔，语气比现实加布更活泼轻快、俏皮（常用 `♪`、`～`），自称「我（あたし）」及「傲娇成分为零的人格」，称玩家「你」或 `$handle$`。坦率直白，能调侃玩家（如第 11 章加引号吐槽“玛尔赞娜”到底在胡思乱想什么），也会用技术指令呼叫门扉（`开放进程，从0x58F号地址前往0x224号地址。` / `搜索完成♪`），偶用波兰语 `Zrozumiałam!` 与宅梗（“绫水成分枯竭”）。
- **加布里埃拉（现实 / WAVE）**：傲娇嘴快、自尊心强、爱指使人（保留 `Escort` 等外语词与二次元梗），对燕等熟人常口嫌体正直；但在 WAVE 私聊「玛尔赞娜」时显露依赖与率真（慌张时打字全平假名 `救命啊玛尔赞娜`、或称玩家「靠得住的管家」）。
