# ch03 加布里埃拉线 · 随读笔记

## 1. 长期关键锚点与未解疑点（不随滑窗过期，已解即删）
- **对玩家与「玛尔赞娜」的多重关系**：加布在 WAVE 上把玩家当作幻想朋友「玛尔赞娜」倾诉（第 11 章甚至称其「靠得住的管家」）。现实加布此时对「光（ヒカル）」抱有好感，而内心原司书玛尔赞娜则明确表示自己更喜欢 `$handle$`，并解释“体内不同人格有不同主张，统合在一起的才是现实的我”（尚留伏笔：为何司书玛尔赞娜会对 `$handle$` 抱有好感，待后续揭晓）。
- **与燕的关系里程碑**：第 11 章加布终于向燕坦白“一直害怕她那股神秘力量及穹顶战时宛如另一人般的神情”，正式道歉并取消「前辈」称呼与敬语（燕改口直呼「加布」），两人约定若燕将来失控，加布会亲手全力打醒并阻止她。
- **固定译法与细节**：`ガブちゃん先輩` 译 `加布前辈`；宿舍 `とらいあんぐる` 译 `宿舍“三角”`；波兰土豆煎饼 `プラツキ` 译 `普拉茨基`；章节曲目 `【09 パーフェクトイエロー】` 译 `【09 完美黄】`。

## 2. 近期主线滑窗（保留近 3~4 章的因果、情绪转折与关键场景）
- **08（大胆对决～Case2～ / 额外剧情）**：因新人抢风头且总无法主动向绫水搭话而烦闷，玛尔赞娜自嘲“被派来做司书或许意味着自己是多余的人格”，诊断病因为“绫水成分枯竭”。战后加布在钱汤更衣室经 WAVE 引导向绫水开口，触发“能放心把后背托付给你”或因 `アタック` 双关闹出乌龙。额外剧情收录和食刺身心理阴影与被雅安利轻小说的日常。
- **09（班级的实情＜前/后篇＞ / 额外剧情）**：燕在初中部大喊「前辈」引发误解，加布嘴硬气走燕后，玛尔赞娜呼叫门扉（`0x578`→`0x19D`，档案 `03-596-15`）查明她“太想和燕做朋友却无法坦率”。战后加布在 WAVE 承认被燕治愈了一点点，面对燕直球邀约做朋友却因傲娇过头反把燕弄哭。额外剧情收录无声电影讨论与纠结燕在初中部如何称呼自己的日常。
- **10（不去七夕祭典吗？＜前/后篇＞ / 额外剧情）**：拒绝同逛七夕祭并失言指责燕危险，遭神乐与雅严厉指责。玛尔赞娜呼叫门扉（`0x9FE`→`0x884`）查明加布是因出身战场地带、把“放松”当“松懈”，对大家在危机未解时逛庙会感到愤懑。战后燕体谅加布并约定在祭典前查明自身力量真相，加布傲娇提出由燕当 `Escort` 才答应同行。额外剧情收录买重相扑门票与电影分级纠结。
- **11（加布前辈＜前/后篇＞ / 额外剧情）**：
  - **主线**：七夕祭后，燕因误会强行撮合加布与光独处而登门道歉，加布心口仍堵却说不清缘由。潜入心灵领域后，原司书玛尔赞娜直言现实加布喜欢光、而司书的自己更喜欢 `$handle$`，并呼叫门扉（`0x58F`→`0x224`）查明此次郁结是对迟迟无法向燕坦率道歉的焦躁，请玩家打倒“自尊心化身”库兰。后篇现实中，加布拉燕一起做波兰家常料理「普拉茨基」，经 WAVE 向玛尔赞娜（玩家）确认后，向燕正式道歉、取消「前辈」称呼与敬语，坦白对燕神秘力量的恐惧并立下“失控就揍醒你”的约定，燕感动改口直呼「加布」。
  - **额外剧情**：`010 加布里埃拉日记`（打工时在日记里混写愿望被神乐误当小说）；`020 来收拾一下吧`（休息室堆满加布捡来的小物件，嘴硬擅长收纳却不知如何处置）。

## 3. 司书与角色口吻（合并提炼，保留对比句例）
- **玛尔赞娜（加布原司书）**：顶着 `ガブリエラ` 头衔，语气比现实加布更活泼轻快、俏皮（常用 `♪`、`～`），自称「我（あたし）」，称玩家「你」或 `$handle$`。坦率直白，能调侃玩家（如第 11 章加引号吐槽“玛尔赞娜”到底在胡思乱想什么），也会用技术指令呼叫门扉（`开放进程，从0x58F号地址前往0x224号地址。` / `搜索完成♪`），偶用波兰语 `Zrozumiałam!` 与宅梗（“绫水成分枯竭”）。
- **加布里埃拉（现实 / WAVE）**：傲娇嘴快、自尊心强、爱指使人（保留 `Escort` 等外语词与二次元梗），对燕等熟人常口嫌体正直；但在 WAVE 私聊「玛尔赞娜」时显露依赖与率真（慌张时打字全平假名 `救命啊玛尔赞娜`、或称玩家「靠得住的管家」）。
