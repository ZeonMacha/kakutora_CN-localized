# ch03 加布里埃拉线 · 随读笔记

## 1. 长期关键锚点与未解疑点（不随滑窗过期，已解即删）
- **对玩家与「玛尔赞娜」的多重关系**：加布在 WAVE 上把玩家当作幻想朋友「玛尔赞娜」倾诉（第 11 章甚至称其「靠得住的管家」）。现实加布此时对「光（ヒカル）」抱有好感，而内心原司书玛尔赞娜则明确表示自己更喜欢 `$handle$`（第 18 章直白告白「我果然还是很喜欢 `$handle$`……最喜欢了」，第 21 章危机中也再次向 `$handle$` 表白「我果然还是最喜欢你了」），并解释“体内不同人格有不同主张，统合在一起的才是现实的我”（第 16 章坦言不清楚其他人格的想法，为何对 `$handle$` 抱有好感尚留伏笔）。
- **玛尔赞娜的“十字架”伏笔**：第 18 章在心之房间被 `$handle$` 追问是否真的毫无心结时，玛尔赞娜举婚姻欺诈作比喻，强调“心中有伤痕与‘现在过得很幸福’是两码事”，并在被追问“难道这么小就遭遇过婚姻欺诈”时罕见失态打断话题，要求对方忘掉刚才的话（待后续揭晓其背负的“十字架”真相）。
- **心因性失声症（仅对一定年龄以上男性发不出声）**：第 15 章现实加布在 WAVE 上向 `$marzanna$` 坦白并非男性恐惧症或洁癖，而是“心因性失声症”（面对小孩正常，面对一定年龄以上男性发不出声音），尚不知具体成因；内心原司书玛尔赞娜本欲借门扉让 `$handle$` 解决，却发现烦恼正涉及 `$handle$` 本人，总意只允许暂且透露一点苗头，真正理由待后续揭晓。
- **心灵领域异变爆发与刺客现身（第 21 章转折）**：第 13、19 章玛尔赞娜对绫水持怀疑平衡派态度、对燕则更积极；第 19 章 `$handle$` 目睹加布心之房间周围已现恐怖异变，但玛尔赞娜本人未察觉。至第 21 章前篇，心之房间已如“地狱绘卷”，一名自称“加布里埃拉人格之一、自始反对司书制度”的神秘人格 `？？？` 现身刺杀玛尔赞娜，称其他心之司书已接连成为祭品被替换为更强的『半人格』，欲彻底切断加布心灵与外界的联系；玛尔赞娜向 `$handle$` 求助并肩迎战。
- **与燕的关系里程碑**：第 11 章加布终于向燕坦白“一直害怕她那股神秘力量及穹顶战时宛如另一人般的神情”，正式道歉并取消「前辈」称呼与敬语（燕改口直呼「加布」），两人约定若燕将来失控，加布会亲手全力打醒并阻止她。
- **固定译法与细节**：`ガブちゃん先輩` 译 `加布前辈`；真幌/绫水司书称呼 `ギャヴィ` 译 `加维`；`まゆちん` 译 `小茧`；宿舍 `とらいあんぐる` 译 `宿舍“三角”`；波兰土豆煎饼 `プラツキ` 译 `普拉茨基`；手游 `カプドラ` 译 `卡普多拉`；`ギガスマートエキスポ / ギガスマ` 译 `GigaSmart博览会 / GigaSma`；秘语 `【白昼夢の迷宮】` 译 `【白日梦的迷宫】`、`【別名は花子さん】` 译 `【别名是花子】`、`【それが子供の仕事】` 译 `【那就是孩子的本分】`、`【闇夜に霜の降る如く】` 译 `【犹如暗夜降霜】`、`【口にする日を】` 译 `【说出口的那天】`、`【おどかさないで！】` 译 `【别吓我啊！】`；厅内干部隐语 `四角ダルマ` 暂译 `四方达摩`。

## 2. 近期主线滑窗（保留近 3~4 章的因果、情绪转折与关键场景）
- **17（礼仪还是娱乐＜前/后篇＞ / 额外剧情）**：
  - **主线**：7月24日（PhenoMENON战结束当晚），加布因神乐擅自行动与燕袒护神乐而不快，随后得知本次 PhenoMENON 诱因正是「卡普多拉」恶性 BUG，因未催促官方修复而愧疚。潜入心灵领域（`0x58F`→`0x224`）后向 `$handle$` 剖白负罪感；后篇在 WAVE 上释怀并被雏、茧拉去打新活动副本转换心情。
  - **额外剧情**：`010 多放点假`（向真幌讨休假，得知剧场历史后被打动并婉拒只给自己减班）；`020 一展身手`（6月25日户外射击场与圣翔比试，分支含让步险胜与真刀真枪94:96惜败）。
- **18（总觉得不对劲＜前/后篇＞ / 额外剧情）**：
  - **主线**：7月27日放学后，加布在 CD 店偶遇同样纠结于是否买 MENOW CD 试探神乐的绫水。潜入心灵领域（`0x122`→`0x9BF`）后，玛尔赞娜因“是否幸福”短暂失态，随后肯定出于善意去了解他人。后篇加布说服绫水一同买下 CD，嘴硬却仍抱有一丝搞好关系的期待。
  - **额外剧情**：`010 梦想的打工`（7月15日咖啡店，羡慕可爱制服并约定赢回自由后去尝试）；`020 能说出口吗？`（7月17日剧场打工，圣翔与光帮搬零件，加布因失声症无法亲口道谢而在 WAVE 上请玩家代发消息）。
- **19（过于在意之战＜前/后篇＞ / 额外剧情）**：
  - **主线**：8月18日（合宿第二天），加布与绫水久违地双人模拟战后被绫水冷淡敷衍，在 WAVE 上抱怨。潜入心灵领域（`0x444`→`0x39A`）后，穿着泳衣的玛尔赞娜对“周围太恐怖”毫不知情，只觉“绫水怀疑派”变强。后篇玩家在 WAVE 提醒绫水叙旧，两人回忆初入队时对抗喷火三十米霸王龙等往事，令加布害羞不已。
  - **额外剧情**：`010 礁岩洞窟`（8月22日被雏、圣翔、光一路叫着“队长”跟到洞内小沙滩）；`020 横须贺的祭典`（8月20日傍晚逛祭典糖人摊位）。
- **21（第 20 章为共用 MV 空缺，19 后直连 21）**：
  - **主线**：8月23日（合宿中），雅带众人穿过田间小路前往“黑崎之鼻”海湾与幽暗洞窟。燕在洞内怕黑却强撑，加布在 WAVE 上吐槽又暗自纠结是否牵她手；潜入心灵领域后，玛尔赞娜仍未察觉“地狱绘卷”般的异变，随即遭反对司书制度的神秘人格 `？？？` 现身刺杀，玛尔赞娜向 `$handle$` 求助迎战。后篇回到现实，加布主动伸手想牵燕却被“牵手不好走路”婉拒，抵达洞窟深处头顶通天亮处后众人心境转晴；可神乐随后同样提出牵手时燕也婉拒并提议唱歌，加布见燕对神乐的态度与对自己不同，心里泛起酸意却对绫水嘴硬掩饰。
  - **额外剧情**：`010 恋之崎家的味道`（8月21日午后合宿，加布向雅妈妈学做清爽沙拉给苦夏的燕尝鲜，大受大家欢迎）；`020 夜晚的恐惧`（8月25日凌晨两点半，加布听完怪谈不敢独自去古民居厕所，撞见熬夜玩电脑的雅才虚惊一场并得知走廊开关位置，取得秘语 `【别吓我啊！】`）。

## 3. 司书与角色口吻（合并提炼，保留对比句例）
- **玛尔赞娜（加布原司书）**：顶着 `ガブリエラ` 头衔，语气比现实加布更活泼轻快、俏皮（常用 `♪`、`～`），自称「我（あたし）」及「傲娇成分为零的人格」，称玩家「你」或 `$handle$`。坦率直白，能调侃玩家（如泳衣事件），也会用技术指令呼叫门扉（`开放进程，从0x444号地址前往0x39A号地址。` / `搜索完成♪`），偶用波兰语 `Zrozumiałam!` 与宅梗；但在触及“自身背负的十字架”等核心伤痛时会突然激动失态并强行终止话题。
- **神秘刺客 `？？？`（第 21 章现身的加布反对派人格）**：自称「我（あたし）」，称玛尔赞娜「你（あんた/貴方）」，语气冷硬决绝、直截了当，视司书为祭品与碍事的外部连接。
- **加布里埃拉（现实 / WAVE）**：傲娇嘴快、自尊心强、爱指使人（保留 `Escort` 等外语词与二次元梗），对熟人常口嫌体正直；但在 WAVE 私聊「玛尔赞娜」时显露依赖与率真。
- **来访的绫水（第 15 章心之扉串门）**：语气温和从容且略带俏皮（称加布 `加维`，称玩家 `$handle$`，偶用 `拜・托・啦♪`），替加布解围与打圆场。
