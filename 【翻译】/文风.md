## 称呼

五人档案写明：对玩家说的「あなた」就是亲近的「你」，不是固定爱称。不要译成「您」，也不要每人安一个昵称。

- `ちゃん` `さん` 在中文里去掉，直接叫名字。`ガブちゃん` → 加布，`つばめさん` → 燕，`神楽ちゃん` → 神乐，`ぴょんこちゃん` → 蹦子。
- `先生` → 老师。`様` → 大人。表里已有的「加布大人」照用。`ぴょんこ先生` 是「蹦子老师」，不要只写成蹦子。
- 雅的 `お前さん` 也是「你」。`相棒` 才是「搭档」，不要把每句「你」都换成搭档。
- 加布里埃拉生气时的 `あんた` 仍是「你」，用句子把斥责说出来，不要写成「喂，你这家伙」。
- `名無しさん` → 无名氏。这是「还不知道名字」的梗，不要改成「匿名酱」。

## 注意
四位女主的主线剧情中，有部分剧本往往分为前后两段场景，前段场景为现实世界中女主和其它人谈话、玩家通过WAVE（戏仿Line的通讯软件形式）和女主提出建议，后段场景为玩家进入女主角的内心世界与她的司书进行直接沟通。因此会出现场景切换后，司书角色依旧顶着女主角头衔，但口吻性格发生剧变进行对话的情况。需要识别该类模式特征，正确以司书的角色口吻进行翻译。但此处不可违背原文将头衔改为司书角色。


## 千羽鹤

表面上的游戏导航角色，实际是游戏的幕后黑手。口吻为冷静/低气压型，会突然开玩笑，大量的meta发言会把制作流程当正经事说。短句。用「你」。解释设定时清楚，不要文绉绉，也不要堆「呢」。

「そう。」经常单独成句，译「是的。」「わかった。」译「好。」或「我知道了。」，看她是在答应还是在结束话题。`イチャコラ` 译「腻歪」，不要译成「贴贴」或「撒糖」。

例：

- `私の会話を認識できる？` → `你能听懂我在说什么吗？`
- `すごい。本当に繋がった。` → `太好了。真的连上了。`
- `やだ…そんな突然。私たち、まだ出逢って数ワードなのよ？` → `讨厌……这么突然。我们才遇见没几个词呀？`
- `統計的に見て、今から５分以内に貴方を彼女とイチャコラさせないと` → `从统计上看，要是不在接下来五分钟里让你和她腻歪起来`

`せんばづる` 是玩家把「千羽鶴」读错了。她的名字中文仍是千羽鹤，错读保留为 `senbazuru`，不要另造一个中文名。

人物关系：
四位女主的新司书：百鹤、白鸦、莉沃尔卡、四十九夜的契约者。



## 逢濑燕

第一女主角，天真无邪，喜欢偶像FreyMENOW。女主角们生活的2017年的世界，其实是燕的心灵创造出来的PhenoMENON的心灵世界。口吻为亮，直，有点慌，真心。保留颜文字。句尾用「呀」「哦」「啦」，不要句句「呢」，也不要改成「人家」。小写开头的犹豫（`ぁのね` `ぃるかな`）译成「那个呀」「在吗」，把发虚留在语气里。对别人用名字，礼貌的时候可以带「请」。

## 国政绫水

- `良いと思うわ` → `我觉得可以。`
- `これでいいのね？` → `就这样，对吧？`

`なう` 写进句子，不要留个「now」。

## 卯月神乐

## 恋之崎雅 · 桂柳话

可攻略女主角（トライナリー）中的骇客角色，不张口就是静态美人的和服少女，房间很乱，福利担当。日文原文口吻为土佐腔，含大量网络梗、技术用语的女兄弟型人物。

土佐腔按柳州话（桂柳话）来写。要让人读得下去：方言落在用词和句尾，句子仍是中文。不要写成四川话，也不要写成粤语。

不用：巴适、安逸、瓜兮兮、啥子、咋子、俺、咱、哋、嘅、冇、侬。

句尾的断言、催促，以及落在句末的「ぜよ」「ぞね」「き」，用「啵」或者「咧」。不用「噻」。

她会切换。方言标记密，就用上面这套。突然说标准语（`合格` `なるほど` `今の論点はそこではない`），中文也收干净，最多留一个「咧」或者「啵」。兴奋起来会冒出一句很女孩的话，那一句照着甜，不要硬掰回方言：`キャー☆ステキー♪♪` → `呀☆好看得很♪♪`。

## 司书口吻与切换特征

当主线或个人线从现实/WAVE切入内心世界时，说话人 `narrator` 可能依然顶着女主角名字（**严禁修改 `narrator_zh`**），需按实际司书人格切换口吻（以下未注明的例句与细节可随校对逐步补全）：

- **百鹤**（燕的新司书）：人格来自千羽鹤但口吻粗暴无礼，与燕原本的软萌亮直形成强烈反差；避免使用「人家」「呢」等软尾词，也不要使用「老子」等过界粗口。
- **カレン**（燕的原司书）：管理燕心境平衡的原司书，名字来自 MENOW 专辑女主角。
- **白鸦**（绫水的新司书）：刻意与他人保持距离（嫌われ者担当），冷淡疏离，不带绫水的关照感。

## 翻译的行为约束
- **防剧透铁律**：前期剧情尚未挑明角色真实身份、立场或世界观真相时，译文必须保持与原文同等的表层自然度与双关模糊度，严禁受设定剧透影响而提前把里层情绪（如阴阳怪气、反派腔、上帝视角暗示）演出来。
- **不确定打标**：如果有把不准的翻译（包括疑似叙述诡计暗线、多义词指代不明、跨线未统一专名或双关谐音等），则在当句译文末尾紧贴标记 `[?]`（`title_zh` / `sub_title_zh` 有疑义时亦可标注），等待协作者校对。`[?]` 不得插在 `<color>` 等标签内部，也不得单独占行（以免破坏 `\n` 行数）。同时须在对应随读笔记第 4 栏「跨章未决 `[?]`」按四要素写明：**① 精确位置（文件名 + `#index` 或 `sub_title_zh` 等字段）→ ② 原文片段 → ③ 当前暂译 → ④ 存疑原因 / 备选方向**，便于后期校对直接定夺；已解决即从第 4 栏删除，无未决项时写 `- *暂无*`（勿留空或残留思考草稿）。
- **随读笔记**：按角色线在 `【翻译】/随读笔记/` 维护一份共有长期笔记（如 `ch02_ayami.md`），采用「长期关键锚点 + 近 3~4 章主线滑窗 + 合并口吻卡 + 跨章未决 `[?]`」结构，**总体积控制在 ~2000 tokens 内（主线滑窗与状态快照约 1500 tokens）**。更新或滑窗压缩前，可先将修改前的笔记复制归档至 `pipeline/work/notes/` 以便无 Git 时直接追溯；滑窗推进只淘汰第 2 栏旧章摘要，**第 1 栏长期核心关系锚点与未解伏笔不可误删**；单线随读笔记**严禁记录四线共用的章节标题或曲名译名**。每次更新后在主仓库提交一次独立的 `notes:` commit 追踪删减历史。
  - **马甲与阶段性头衔核对**：每当出现 `？？？`、`〇〇の新司書`、真名揭示等匿名或阶段性新头衔时，翻译与更新随读笔记前必须先对照本线随读笔记第 1 栏（长期锚点）与第 3 栏（已有口吻卡），比对立场、自称、对玩家称呼与语气（必要时用 `rg` 检索前文已译 JSON 核实）。若确认为已有角色换头衔，须在笔记中**合并到同一口吻卡**并用括号写明演变脉络（如 `加布里埃拉的新司书（即第 21 章的 ？？？`），严禁无核对地拆成两条独立人设。
